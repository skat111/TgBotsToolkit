# aiogram Telegram bot starter

Requires Python 3.11+.

```sh
python -m venv .venv
python -m pip install -r requirements.txt
```

Set `BOT_TOKEN` in the environment. Optionally set `MENU_PHOTO` to a Telegram `file_id` or public image URL and `CUSTOM_EMOJI_ENABLED=true` when the bot is eligible. Run `python bot.py`.
