#### RichBlockFooter

A footer, corresponding to the HTML tag `<footer>`.

| Field | Type | Description |
| --- | --- | --- |
| type | String | Type of the block, always “footer” |
| text | [RichText](https://core.telegram.org/bots/api#richtext) | Text of the block |
