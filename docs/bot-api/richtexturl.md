#### RichTextUrl

A text with a link.

| Field | Type | Description |
| --- | --- | --- |
| type | String | Type of the rich text, always “url” |
| text | [RichText](https://core.telegram.org/bots/api#richtext) | The text |
| url | String | URL of the link |
