#### RichTextMention

A mention by a username.

| Field | Type | Description |
| --- | --- | --- |
| type | String | Type of the rich text, always “mention” |
| text | [RichText](https://core.telegram.org/bots/api#richtext) | The text |
| username | String | The username |
