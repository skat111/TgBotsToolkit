#### EmojiTypeCustomEmoji

A custom emoji.

| Field | Type | Description |
| --- | --- | --- |
| type | String | Type of the emoji, always “custom_emoji” |
| custom_emoji_id | String | Identifier of the custom emoji. Use [getCustomEmojiStickers](https://core.telegram.org/bots/api#getcustomemojistickers) to get full information about the sticker. |
