#### RichBlockParagraph

A text paragraph, corresponding to the HTML tag `<p>`.

| Field | Type | Description |
| --- | --- | --- |
| type | String | Type of the block, always “paragraph” |
| text | [RichText](https://core.telegram.org/bots/api#richtext) | Text of the block |
