#### RichTextBotCommand

A bot command.

| Field | Type | Description |
| --- | --- | --- |
| type | String | Type of the rich text, always “bot_command” |
| text | [RichText](https://core.telegram.org/bots/api#richtext) | The text |
| bot_command | String | The bot command |
