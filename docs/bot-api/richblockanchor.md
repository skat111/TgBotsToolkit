#### RichBlockAnchor

A block with an anchor, corresponding to the HTML tag `<a>` with the attribute `name`.

| Field | Type | Description |
| --- | --- | --- |
| type | String | Type of the block, always “anchor” |
| name | String | The name of the anchor |
