#### TransactionPartnerFragment

Describes a withdrawal transaction with Fragment.

| Field | Type | Description |
| --- | --- | --- |
| type | String | Type of the transaction partner, always “fragment” |
| withdrawal_state | [RevenueWithdrawalState](https://core.telegram.org/bots/api#revenuewithdrawalstate) | *Optional*. State of the transaction if the transaction is outgoing |
