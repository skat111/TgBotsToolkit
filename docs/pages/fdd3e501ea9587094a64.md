### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **flags** | [#](https://core.telegram.org/type/%23) | Flags, see [TL conditional fields](https://core.telegram.org/mtproto/TL-combinators#conditional-fields) |
| **out** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).1?[true](https://core.telegram.org/constructor/true) | Whether the message is outgoing |
| **mentioned** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).4?[true](https://core.telegram.org/constructor/true) | Whether we were mentioned in the message |
| **media\_unread** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).5?[true](https://core.telegram.org/constructor/true) | Whether there are some **unread** mentions in this message |
| **silent** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).13?[true](https://core.telegram.org/constructor/true) | If true, the message is a silent message, no notifications should be triggered |
| **id** | [int](https://core.telegram.org/type/int) | The message ID |
| **user\_id** | [long](https://core.telegram.org/type/long) | The ID of the sender (if `outgoing` will be the ID of the destination) of the message |
| **message** | [string](https://core.telegram.org/type/string) | The message |
| **pts** | [int](https://core.telegram.org/type/int) | [PTS](https://core.telegram.org/api/updates) |
| **pts\_count** | [int](https://core.telegram.org/type/int) | [PTS count](https://core.telegram.org/api/updates) |
| **date** | [int](https://core.telegram.org/type/int) | [date](https://core.telegram.org/api/updates) |
| **fwd\_from** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).2?[MessageFwdHeader](https://core.telegram.org/type/MessageFwdHeader) | Info about a forwarded message |
| **via\_bot\_id** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).11?[long](https://core.telegram.org/type/long) | Info about the inline bot used to generate this message |
| **reply\_to** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).3?[MessageReplyHeader](https://core.telegram.org/type/MessageReplyHeader) | Reply and [thread](https://core.telegram.org/api/threads) information |
| **entities** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).7?[Vector](https://core.telegram.org/type/Vector%20t)<[MessageEntity](https://core.telegram.org/type/MessageEntity)> | [Entities](https://core.telegram.org/api/entities) for styled text |
| **ttl\_period** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).25?[int](https://core.telegram.org/type/int) | Time To Live of the message, once message.date+message.ttl\_period === time(), the message will be deleted on the server, and must be deleted locally as well. |
