## Description

Changes the status of a chat member; requires can\_invite\_users member right to add a chat member, can\_promote\_members administrator right to change administrator rights of the member, and can\_restrict\_members administrator right to change restrictions of a user. This function is currently not suitable for transferring chat ownership; use [transferChatOwnership](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1transfer_chat_ownership.html) instead. Use [addChatMember](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1add_chat_member.html) or [banChatMember](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1ban_chat_member.html) if some additional parameters needs to be passed.

Returns object\_ptr<Ok>.
