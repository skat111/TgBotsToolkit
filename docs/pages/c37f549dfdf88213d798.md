# messages.composeMessageWithAI

Source: https://core.telegram.org/method/messages.composeMessageWithAI

Invokes telegram's AI Editor that can translate, transform, fixup and/or emojify your message in a number of different ways, privately powered by [Cocoon](https://cocoon.org), see [here »](https://core.telegram.org/api/ai#compose-messages) for more info!

```
messages.composedMessageWithAI#90d7adfa flags:# result_text:TextWithEntities diff_text:flags.0?TextWithEntities = messages.ComposedMessageWithAI;
---functions---
messages.composeMessageWithAI#daecc589 flags:# proofread:flags.0?true emojify:flags.3?true text:TextWithEntities translate_to_lang:flags.1?string tone:flags.2?InputAiComposeTone = messages.ComposedMessageWithAI;
```

### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **flags** | [#](https://core.telegram.org/type/%23) | Flags, see [TL conditional fields](https://core.telegram.org/mtproto/TL-combinators#conditional-fields) |
| **proofread** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).0?[true](https://core.telegram.org/constructor/true) | If set, proofreads and fixes mistakes in the message |
| **emojify** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).3?[true](https://core.telegram.org/constructor/true) | If set, adds emojis to the message |
| **text** | [TextWithEntities](https://core.telegram.org/type/TextWithEntities) | The message |
| **translate_to_lang** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).1?[string](https://core.telegram.org/type/string) | If set, translates the message to the specified language |
| **tone** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).2?[InputAiComposeTone](https://core.telegram.org/type/InputAiComposeTone) | If set, rephrases the message using the specified [AI composer tone »](https://core.telegram.org/api/ai#ai-compose-tones) |

[messages.ComposedMessageWithAI](https://core.telegram.org/type/messages.ComposedMessageWithAI)

### Possible errors

| Code | Type | Description |
| --- | --- | --- |
| 400 | AICOMPOSE_FLOOD_PREMIUM | You've reached the daily limit of AI text transformations, upgrade to [Telegram Premium](https://core.telegram.org/api/premium) to get **50x** times more AI text transformations per day! |
| 500 | AICOMPOSE_TIMEOUT | A timeout occurred while composing the message. |
| 400 | AI_COMPOSE_TASK_MISSING | No AI task was specified. The caller must provide at least one of: proofread, translate (with a target language), tone, or emojify. |
| 400 | MESSAGE_EMPTY | The provided message is empty. |
