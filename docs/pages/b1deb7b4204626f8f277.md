### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **flags** | [#](https://core.telegram.org/type/%23) | Flags, see [TL conditional fields](https://core.telegram.org/mtproto/TL-combinators#conditional-fields) |
| **client_id** | [long](https://core.telegram.org/type/long) | An arbitrary 64-bit integer: it should be set, for example, to an incremental number when using [contacts.importContacts](https://core.telegram.org/method/contacts.importContacts), in order to retry importing only the contacts that weren't imported successfully, according to the client_ids returned in [contacts.importedContacts](https://core.telegram.org/constructor/contacts.importedContacts).`retry_contacts`. |
| **phone** | [string](https://core.telegram.org/type/string) | Phone number |
| **first_name** | [string](https://core.telegram.org/type/string) | Contact's first name |
| **last_name** | [string](https://core.telegram.org/type/string) | Contact's last name |
| **note** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).0?[TextWithEntities](https://core.telegram.org/type/TextWithEntities) | A private note for this contact, only visible to us; see [here »](https://core.telegram.org/api/contacts#private-notes-for-contacts) for more info on contact notes. |
