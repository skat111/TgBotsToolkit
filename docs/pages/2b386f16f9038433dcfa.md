## Description

Returns an HTTPS link to a message in a chat. Available only if messageProperties.can\_get\_link, or if messageProperties.can\_get\_media\_timestamp\_links and a media timestamp link is generated. This is an offline method.

Returns object\_ptr<MessageLink>.
