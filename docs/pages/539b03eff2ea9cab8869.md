# inputPasskeyCredentialFirebasePNV

Source: https://core.telegram.org/constructor/inputPasskeyCredentialFirebasePNV

Alternative [passkey](https://core.telegram.org/api/passkeys) credential that proves ownership of the account's phone number through a Firebase Phone Number Verification (PNV) token, used on official apps where a full WebAuthn [public-key passkey](https://core.telegram.org/constructor/inputPasskeyCredentialPublicKey) cannot be created, in a way similar to [Firebase SMS authentication »](https://core.telegram.org/api/auth).

{schema}

### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **pnv_token** | [string](https://core.telegram.org/type/string) | Firebase Phone Number Verification token attesting that the user controls the phone number associated with the account. |

### Type

[InputPasskeyCredential](https://core.telegram.org/type/InputPasskeyCredential)
