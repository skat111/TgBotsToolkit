### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **bot** | [InputUser](https://core.telegram.org/type/InputUser) | Bot that owns the web app |
| **random_id** | [long](https://core.telegram.org/type/long) | Unique client message ID to prevent duplicate sending of the same event. See [here »](https://core.telegram.org/api/updates#updatemessageid-updates) for more info on random ID deduplication and updateMessageID mapping. |
| **button_text** | [string](https://core.telegram.org/type/string) | Text of the [keyboardButtonSimpleWebView](https://core.telegram.org/constructor/keyboardButtonSimpleWebView) that was pressed to open the web app. |
| **data** | [string](https://core.telegram.org/type/string) | Data to relay to the bot, obtained from a [`web_app_data_send` JS event](https://core.telegram.org/api/web-events#web-app-data-send). |

### Result

[Updates](https://core.telegram.org/type/Updates)

| --- | --- | --- |

#### [keyboardButtonSimpleWebView](https://core.telegram.org/constructor/keyboardButtonSimpleWebView)

Button to open a [bot mini app](https://core.telegram.org/api/bots/webapps) using [messages.requestSimpleWebView](https://core.telegram.org/method/messages.requestSimpleWebView), without sending user information to the web app.

Can only be sent or received as part of a reply keyboard, use [keyboardButtonWebView](https://core.telegram.org/constructor/keyboardButtonWebView) for inline keyboards.

When pressed, clients must open a [Keyboard Button Mini App](https://core.telegram.org/api/bots/webapps#keyboard-button-mini-apps) using [messages.requestSimpleWebView](https://core.telegram.org/method/messages.requestSimpleWebView), passing `url` to [messages.requestSimpleWebView](https://core.telegram.org/method/messages.requestSimpleWebView).`url`.
