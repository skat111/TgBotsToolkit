## Description

Returns a URL for chat revenue withdrawal; requires owner privileges in the channel chat or the bot. Currently, this method can be used only if [getOption](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1get_option.html)("can\_withdraw\_chat\_revenue") for channels with supergroupFullInfo.can\_get\_revenue\_statistics == true or bots with userFullInfo.bot\_info.can\_get\_revenue\_statistics == true.

Returns object\_ptr<HttpUrl>.
