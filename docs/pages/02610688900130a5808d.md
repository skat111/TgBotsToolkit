# bots.getRequestedWebViewButton

Source: https://core.telegram.org/method/bots.getRequestedWebViewButton

### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **bot** | [InputUser](https://core.telegram.org/type/InputUser) | The bot that owns the Mini App |
| **webapp_req_id** | [string](https://core.telegram.org/type/string) | The Mini App request ID, taken from the [`web_app_request_chat`](https://core.telegram.org/api/web-events#web-app-request-chat) event's `req_id` |

### Result
