## Description

Toggles whether non-administrators can receive only administrators and bots using [getSupergroupMembers](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1get_supergroup_members.html) or [searchChatMembers](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1search_chat_members.html). Can be called only if supergroupFullInfo.can\_hide\_members == true.

Returns object\_ptr<Ok>.
