## Description

A new pending text message was received in a chat with a bot. The message must be shown in the chat for at most [getOption](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1get_option.html)("pending\_text\_message\_period") seconds, replace any other pending message with the same draft\_id, and be deleted whenever any incoming message from the bot in the message thread is received.
