# TDLib: ClientManager Class Reference

Source: https://core.telegram.org/tdlib/docs/classtd_1_1_client_manager.html

## Description

The native C++ interface for interaction with TDLib.

A TDLib client instance can be created through the method [ClientManager::create_client_id](https://core.telegram.org/tdlib/docs/classtd_1_1_client_manager.html#ad62e59d24e523294c0460d25a04913be). Requests can be sent using the method [ClientManager::send](https://core.telegram.org/tdlib/docs/classtd_1_1_client_manager.html#a63503b20c7c431cc4a3f79cfea63eae0) from any thread. New updates and responses to requests can be received using the method [ClientManager::receive](https://core.telegram.org/tdlib/docs/classtd_1_1_client_manager.html#a95ed6da3afd8b605b3bf94f1f8915aff) from any thread after the first request has been sent to the client instance. [ClientManager::receive](https://core.telegram.org/tdlib/docs/classtd_1_1_client_manager.html#a95ed6da3afd8b605b3bf94f1f8915aff) must not be called simultaneously from two different threads. Also, note that all updates and responses to requests should be applied in the same order as they were received, to ensure consistency. Some TDLib requests can be executed synchronously from any thread using the method [ClientManager::execute](https://core.telegram.org/tdlib/docs/classtd_1_1_client_manager.html#ab8ae7eff4a155763950f1d820b7ed25b).

General pattern of usage:

[td::ClientManager](https://core.telegram.org/tdlib/docs/classtd_1_1_client_manager.html) manager;

auto client_id = manager.[create_client_id](https://core.telegram.org/tdlib/docs/classtd_1_1_client_manager.html#ad62e59d24e523294c0460d25a04913be)();

// somehow share the manager and the client_id with other threads,

// which will be able to send requests via manager.send(client_id, ...)

// send some dummy requests to the new instance to activate it

manager.[send](https://core.telegram.org/tdlib/docs/classtd_1_1_client_manager.html#a63503b20c7c431cc4a3f79cfea63eae0)(client_id, ...);

const double WAIT_TIMEOUT = 10.0; // seconds

while (true) {

auto response = manager.[receive](https://core.telegram.org/tdlib/docs/classtd_1_1_client_manager.html#a95ed6da3afd8b605b3bf94f1f8915aff)(WAIT_TIMEOUT);

if (response.object == nullptr) {

continue;

}

if (response.request_id == 0) {

// process response.object as an incoming update of the type td_api::Update for the client response.client_id

} else {

// process response.object as an answer to a request response.request_id for the client response.client_id

}

}
