### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **flags** | [#](https://core.telegram.org/type/%23) | Flags, see [TL conditional fields](https://core.telegram.org/mtproto/TL-combinators#conditional-fields) |
| **official** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).0?[true](https://core.telegram.org/constructor/true) | Whether the language pack is official |
| **rtl** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).2?[true](https://core.telegram.org/constructor/true) | Is this a localization pack for an RTL language |
| **beta** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).3?[true](https://core.telegram.org/constructor/true) | Is this a beta localization pack? |
| **name** | [string](https://core.telegram.org/type/string) | Language name |
| **native_name** | [string](https://core.telegram.org/type/string) | Language name in the language itself |
| **lang_code** | [string](https://core.telegram.org/type/string) | Language code (pack identifier) |
| **base_lang_code** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).1?[string](https://core.telegram.org/type/string) | Identifier of a base language pack; may be empty. If a string is missed in the language pack, then it should be fetched from base language pack. Unsupported in custom language packs |
| **plural_code** | [string](https://core.telegram.org/type/string) | A language code to be used to apply plural forms. See <https://www.unicode.org/cldr/charts/latest/supplemental/language_plural_rules.html> for more info |
| **strings_count** | [int](https://core.telegram.org/type/int) | Total number of non-deleted strings from the language pack |
| **translated_count** | [int](https://core.telegram.org/type/int) | Total number of translated strings from the language pack |
| **translations_url** | [string](https://core.telegram.org/type/string) | Link to language translation interface; empty for custom local language packs |
