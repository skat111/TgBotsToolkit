# e2e.callPacketLargeMsgId

Source: https://core.telegram.org/constructor/e2e.callPacketLargeMsgId

Marker constructor whose CRC32 constructor ID is used when signing the large message ID produced while encrypting [group call packets](https://core.telegram.org/api/end-to-end/group-calls#packet-encryption).

```
e2e.callPacketLargeMsgId#1ce56c2d = e2e.CallPacketLargeMsgId;
```

### Parameters

This constructor does not require any parameters.
