### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **flags** | [#](https://core.telegram.org/type/%23) | Flags, see [TL conditional fields](https://core.telegram.org/mtproto/TL-combinators#conditional-fields) |
| **returned** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).1?[true](https://core.telegram.org/constructor/true) | If set, the placed bid was returned to the user, because it was outbid so much that it fell out of the top [starGiftAuctionState](https://core.telegram.org/constructor/starGiftAuctionState).`gifts_left` positions, meaning that even if no new bids are placed, the user will never receive any gifts, so the bid was completely removed from the auction, and in order to participate again the user must manually make a new bid. |
| **bid_amount** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).0?[long](https://core.telegram.org/type/long) | Contains the amount of the placed bid in [Telegram Stars](https://core.telegram.org/api/stars). |
| **bid_date** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).0?[int](https://core.telegram.org/type/int) | Contains a UNIX timestamp, indicating when the bid was placed. |
| **min_bid_amount** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).0?[long](https://core.telegram.org/type/long) | Contains the minumum allowed bid amount in [Telegram Stars](https://core.telegram.org/api/stars), if set overrides [starGiftAuctionState](https://core.telegram.org/constructor/starGiftAuctionState).`min_bid_amount` for the current user. |
| **bid_peer** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).0?[Peer](https://core.telegram.org/type/Peer) | Contains the peer that will receive the gift, if you end up winning this round |
| **acquired_count** | [int](https://core.telegram.org/type/int) | Contains the number of gifts that were purchased so far in the auction by the current user. |
