### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **flags** | [#](https://core.telegram.org/type/%23) | Flags, see [TL conditional fields](https://core.telegram.org/mtproto/TL-combinators#conditional-fields) |
| **my** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).1?[true](https://core.telegram.org/constructor/true) | Whether the topic was created by the current user |
| **closed** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).2?[true](https://core.telegram.org/constructor/true) | Whether the topic is closed (no messages can be sent to it) |
| **pinned** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).3?[true](https://core.telegram.org/constructor/true) | Whether the topic is pinned |
| **short** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).5?[true](https://core.telegram.org/constructor/true) | Whether this constructor is a reduced version of the full topic information.  If set, only the `my`, `closed`, `id`, `date`, `title`, `icon_color`, `icon_emoji_id` and `from_id` parameters will contain valid information.  Reduced info is usually only returned in topic-related [admin log events »](https://core.telegram.org/api/recent-actions) and in the [messages.channelMessages](https://core.telegram.org/constructor/messages.channelMessages) constructor: if needed, full information can be fetched using [messages.getForumTopicsByID](https://core.telegram.org/method/messages.getForumTopicsByID). |
| **hidden** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).6?[true](https://core.telegram.org/constructor/true) | Whether the topic is hidden (only valid for the "General" topic, `id=1`) |
| **title_missing** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).7?[true](https://core.telegram.org/constructor/true) | If set, the topic has no user-defined title, can only be set for the per-user topics of [bot forums](https://core.telegram.org/api/forum#bot-forums); if this field is set, the topic title likely needs to be changed by the bot. |
| **id** | [int](https://core.telegram.org/type/int) | [Topic ID](https://core.telegram.org/api/forum#forum-topics) |
| **date** | [int](https://core.telegram.org/type/int) | Topic creation date |
| **peer** | [Peer](https://core.telegram.org/type/Peer) | Contains the supergroup/private chat where the topic is located.  This field is useful especially when this object is returned by methods like [messages.getMessages](https://core.telegram.org/method/messages.getMessages), which can return messages and forum topics belonging to different (private chat) peers in the same method call, making it impossible to tell the topic's peer based on the method call parameters or surrounding context. |
| **title** | [string](https://core.telegram.org/type/string) | Topic title |
| **icon_color** | [int](https://core.telegram.org/type/int) | If no custom emoji icon is specified, specifies the color of the fallback topic icon (RGB), one of `0x6FB9F0`, `0xFFD67E`, `0xCB86DB`, `0x8EEE98`, `0xFF93B2`, or `0xFB6F5F`. |
| **icon_emoji_id** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).0?[long](https://core.telegram.org/type/long) | ID of the [custom emoji](https://core.telegram.org/api/custom-emoji) used as topic icon. |
| **top_message** | [int](https://core.telegram.org/type/int) | ID of the last message that was sent to this topic |
| **read_inbox_max_id** | [int](https://core.telegram.org/type/int) | Position up to which all incoming messages are read. |
| **read_outbox_max_id** | [int](https://core.telegram.org/type/int) | Position up to which all outgoing messages are read. |
| **unread_count** | [int](https://core.telegram.org/type/int) | Number of unread messages |
| **unread_mentions_count** | [int](https://core.telegram.org/type/int) | Number of [unread mentions](https://core.telegram.org/api/mentions) |
| **unread_reactions_count** | [int](https://core.telegram.org/type/int) | Number of unread reactions to messages you sent |
| **unread_poll_votes_count** | [int](https://core.telegram.org/type/int) | Number of [unread votes cast in non-anonymous polls »](https://core.telegram.org/api/poll#unread-poll-votes) owned by the user in this forum topic. |
| **from_id** | [Peer](https://core.telegram.org/type/Peer) | ID of the peer that created the topic |
| **notify_settings** | [PeerNotifySettings](https://core.telegram.org/type/PeerNotifySettings) | Notification settings |
| **draft** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).4?[DraftMessage](https://core.telegram.org/type/DraftMessage) | Message [draft](https://core.telegram.org/api/drafts) |
