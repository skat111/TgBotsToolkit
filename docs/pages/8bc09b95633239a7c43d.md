# aicompose.saveTone

Source: https://core.telegram.org/method/aicompose.saveTone

Install or uninstall an [AI composer tone »](https://core.telegram.org/api/ai#ai-compose-tones), adding it to or removing it from the list of saved tones of the current user.

Non-[Premium](https://core.telegram.org/api/premium) users may install up to [aicompose\_tone\_saved\_limit\_default »](https://core.telegram.org/api/config#aicompose-tone-saved-limit-default) tones, [Premium](https://core.telegram.org/api/premium) users up to [aicompose\_tone\_saved\_limit\_premium »](https://core.telegram.org/api/config#aicompose-tone-saved-limit-premium) tones.

### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **tone** | [InputAiComposeTone](https://core.telegram.org/type/InputAiComposeTone) | The tone to save or unsave |
| **unsave** | [Bool](https://core.telegram.org/type/Bool) | If `false`, installs (saves) the tone; if `true`, uninstalls (unsaves) it |

### Result

[Bool](https://core.telegram.org/type/Bool)
