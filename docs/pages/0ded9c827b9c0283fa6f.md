# emojiStatusCollectible

Source: https://core.telegram.org/constructor/emojiStatusCollectible

An owned or [hosted collectible gift »](https://core.telegram.org/api/gifts#hosted-collectible-gifts) as emoji status.

**Cannot** be passed to [account.updateEmojiStatus](https://core.telegram.org/method/account.updateEmojiStatus), must be converted to an [inputEmojiStatusCollectible](https://core.telegram.org/constructor/inputEmojiStatusCollectible) first before passing it to that method.

### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **flags** | [#](https://core.telegram.org/type/%23) | Flags, see [TL conditional fields](https://core.telegram.org/mtproto/TL-combinators#conditional-fields) |
| **collectible\_id** | [long](https://core.telegram.org/type/long) | ID of the collectible (from [starGiftUnique](https://core.telegram.org/constructor/starGiftUnique).`id`). |
| **document\_id** | [long](https://core.telegram.org/type/long) | ID of the [custom emoji](https://core.telegram.org/api/custom-emoji) representing the status. |
| **title** | [string](https://core.telegram.org/type/string) | Name of the collectible. |
| **slug** | [string](https://core.telegram.org/type/string) | Unique identifier of the collectible that may be used to create a [collectible gift link »](https://core.telegram.org/api/links#collectible-gift-link) for the current collectible, or to fetch further info about the collectible using [payments.getUniqueStarGift](https://core.telegram.org/method/payments.getUniqueStarGift). |
| **pattern\_document\_id** | [long](https://core.telegram.org/type/long) | The ID of a pattern to apply on the profile's backdrop, correlated to the [starGiftAttributePattern](https://core.telegram.org/constructor/starGiftAttributePattern) from the gift in `slug`. |
| **center\_color** | [int](https://core.telegram.org/type/int) | Color of the center of the profile backdrop in RGB24 format, from the gift's [starGiftAttributeBackdrop](https://core.telegram.org/constructor/starGiftAttributeBackdrop). |
| **edge\_color** | [int](https://core.telegram.org/type/int) | Color of the edges of the profile backdrop in RGB24 format, from the gift's [starGiftAttributeBackdrop](https://core.telegram.org/constructor/starGiftAttributeBackdrop). |
| **pattern\_color** | [int](https://core.telegram.org/type/int) | Color of the `pattern_document_id` applied on the profile backdrop in RGB24 format, from the gift's [starGiftAttributeBackdrop](https://core.telegram.org/constructor/starGiftAttributeBackdrop). |
| **text\_color** | [int](https://core.telegram.org/type/int) | Color of text on the profile backdrop in RGB24 format, from the gift's [starGiftAttributeBackdrop](https://core.telegram.org/constructor/starGiftAttributeBackdrop). |
| **until** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).0?[int](https://core.telegram.org/type/int) | If set, the emoji status will be active until the specified unixtime. |

#### [inputEmojiStatusCollectible](https://core.telegram.org/constructor/inputEmojiStatusCollectible)

An owned or [hosted collectible gift »](https://core.telegram.org/api/gifts#hosted-collectible-gifts) as emoji status: can only be used in [account.updateEmojiStatus](https://core.telegram.org/method/account.updateEmojiStatus), is never returned by the API.

Note that once set, the status will be returned to users as a [emojiStatusCollectible](https://core.telegram.org/constructor/emojiStatusCollectible) constructor, instead (which **cannot** be passed to [account.updateEmojiStatus](https://core.telegram.org/method/account.updateEmojiStatus), and must be converted to an [inputEmojiStatusCollectible](https://core.telegram.org/constructor/inputEmojiStatusCollectible) first).
