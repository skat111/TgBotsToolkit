## Description

This class is an abstract base class. Represents a data needed to subscribe for push notifications through [registerDevice](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1register_device.html) method. To use specific push notification service, the correct application platform must be specified and a valid server authentication data must be uploaded at <https://my.telegram.org>.
