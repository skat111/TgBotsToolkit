## Description

Changes the login email address of the user. The email address can be changed only if the current user already has login email and passwordState.login\_email\_address\_pattern is non-empty, or the user received [suggestedActionSetLoginEmailAddress](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1suggested_action_set_login_email_address.html) and [isLoginEmailAddressRequired](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1is_login_email_address_required.html) succeeds. The change will not be applied until the new login email address is confirmed with [checkLoginEmailAddressCode](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1check_login_email_address_code.html). To use Apple ID/Google ID instead of an email address, call [checkLoginEmailAddressCode](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1check_login_email_address_code.html) directly.

Returns object\_ptr<EmailAddressAuthenticationCodeInfo>.
