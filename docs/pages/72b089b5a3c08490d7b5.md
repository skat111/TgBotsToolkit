# File reference sources

Source: https://core.telegram.org/api/file-references/sources

A source extractor contains instruction that the client may use to extract a [file source »](https://core.telegram.org/api/file-references#source-extraction): what follows is the full list of file source extractors contained by the current [file reference map file »](https://core.telegram.org/api/file-references#map-file).

See [here »](https://core.telegram.org/api/file-references#source-extraction) for more info on file source extractors.

  ```
  fileSourceStickerSet{stickerset: extractInputStickerSetFromDocumentAttributesAndStore(document.attributes)}
  ```
