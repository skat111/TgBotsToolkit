# e2e.callPacket

Source: https://core.telegram.org/constructor/e2e.callPacket

Marker constructor whose CRC32 constructor ID is used when deriving and authenticating [encrypted group call packets](https://core.telegram.org/api/end-to-end/group-calls#packet-encryption).

```
e2e.callPacket#40a6bee9 = e2e.CallPacket;
```
