## Description

Download or upload file speed for the user was limited, but it can be restored by subscription to Telegram Premium. The notification can be postponed until a being downloaded or uploaded file is visible to the user. Use [getOption](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1get_option.html)("premium\_download\_speedup") or [getOption](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1get_option.html)("premium\_upload\_speedup") to get expected speedup after subscription to Telegram Premium.
