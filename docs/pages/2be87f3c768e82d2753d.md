### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **flags** | [#](https://core.telegram.org/type/%23) | Flags, see [TL conditional fields](https://core.telegram.org/mtproto/TL-combinators#conditional-fields) |
| **peer** | [InputPeer](https://core.telegram.org/type/InputPeer) | Owner of the collectible gift: equal to [starGiftUnique](https://core.telegram.org/constructor/starGiftUnique).`owner_id`. |
| **slug** | [string](https://core.telegram.org/type/string) | Identifier of the collectible gift: equal to [starGiftUnique](https://core.telegram.org/constructor/starGiftUnique).`slug`. |
| **price** | [StarsAmount](https://core.telegram.org/type/StarsAmount) | Offer price, in stars or TON. |
| **duration** | [int](https://core.telegram.org/type/int) | Duration of the offer, in seconds: must be one of `21600`, `43200`, `86400`, `129600`, `172800`, or `259200`; can also be `120` in test mode. |
| **random_id** | [long](https://core.telegram.org/type/long) | Random 64-bit identifier used to avoid sending the same offer twice in case of network issues. See [here »](https://core.telegram.org/api/updates#updatemessageid-updates) for more info on random ID deduplication and updateMessageID mapping. |
| **allow_paid_stars** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).0?[long](https://core.telegram.org/type/long) | If the destination peer has [paid messages »](https://core.telegram.org/api/paid-messages) enabled, specifies the amount of [Telegram Stars](https://core.telegram.org/api/stars) the sending user has agreed to pay in order to send the offer (in addition to the amount for the offer itself, contained in `price`). |

### Result

[Updates](https://core.telegram.org/type/Updates)

| 400 | INVOICE_INVALID | The specified invoice is invalid. |
| 400 | PEER_ID_INVALID | The provided peer id is invalid. |
| 400 | RESELL_STARS_TOO_FEW | The offered price is too low. |

| 400 | STARGIFT_OFFER_NOT_ALLOWED | You can't send a purchase offer for this gift. |
| 400 | STARGIFT_SLUG_INVALID | The specified gift slug is invalid. |

#### [Telegram Gifts](https://core.telegram.org/api/gifts)

Users can send Gifts to their friends. The recipients of gifts can display them on their profile pages or turn them into Telegram Stars ». Telegram Stars can be used for many things, including supporting creators and buying services in mini apps.
