### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **flags** | [#](https://core.telegram.org/type/%23) | Flags, see [TL conditional fields](https://core.telegram.org/mtproto/TL-combinators#conditional-fields) |
| **tone** | [InputAiComposeTone](https://core.telegram.org/type/InputAiComposeTone) | The tone to edit |
| **display\_author** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).0?[Bool](https://core.telegram.org/type/Bool) | If set, changes whether the current user is publicly credited as the author of the tone (ternary value, can be not set, set and true, set and false). |
| **emoji\_id** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).1?[long](https://core.telegram.org/type/long) | If set, the new [custom emoji ID](https://core.telegram.org/api/custom-emoji) of the tone's icon |
| **title** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).2?[string](https://core.telegram.org/type/string) | If set, the new human-readable tone name, up to [aicompose\_tone\_title\_length\_max »](https://core.telegram.org/api/config#aicompose-tone-title-length-max) UTF-8 characters long |
| **prompt** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).3?[string](https://core.telegram.org/type/string) | If set, the new prompt that describes how the AI should rephrase messages using this tone, up to [aicompose\_tone\_prompt\_length\_max »](https://core.telegram.org/api/config#aicompose-tone-prompt-length-max) UTF-8 characters long |
