## Description

Loads more active stories from a story list. The loaded stories will be sent through updates. Active stories are sorted by the pair (active\_stories.order, active\_stories.story\_poster\_chat\_id) in descending order. Returns a 404 error if all active stories have been loaded.

Returns object\_ptr<Ok>.
