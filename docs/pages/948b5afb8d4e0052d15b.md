# TDLib: ClientActor Class Reference

Source: https://core.telegram.org/tdlib/docs/classtd_1_1_client_actor.html

Inherits Actor.

## Description

This is a low-level Actor interface for interaction with TDLib. The interface is a lot more flexible than the [ClientManager](https://core.telegram.org/tdlib/docs/classtd_1_1_client_manager.html) interface, however, for most usages the [ClientManager](https://core.telegram.org/tdlib/docs/classtd_1_1_client_manager.html) interface should be sufficient.
