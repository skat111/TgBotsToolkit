### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **peer** | [InputPeer](https://core.telegram.org/type/InputPeer) | Basic group, supergroup or channel whose video chat/livestream default should be changed |
| **join_as** | [InputPeer](https://core.telegram.org/type/InputPeer) | Eligible peer to use by default when joining the dialog's video chats/livestreams, selected from [phone.getGroupCallJoinAs](https://core.telegram.org/method/phone.getGroupCallJoinAs) |

### Result

[Bool](https://core.telegram.org/type/Bool)

### Possible errors

| Code | Type | Description |
| --- | --- | --- |
| 400 | JOIN_AS_PEER_INVALID | The specified peer cannot be used to join a group call. |
| 400 | PEER_ID_INVALID | The provided peer id is invalid. |

### Related pages

#### [phone.getGroupCallJoinAs](https://core.telegram.org/method/phone.getGroupCallJoinAs)

Get a list of peers that can be used to join a [video chat or livestream »](https://core.telegram.org/api/group-calls#joining-a-group-call-on-behalf-of-owned-channels), presenting yourself as a specific user/channel.

This method cannot be used for live stories or conference calls. To comment or react in a live story as another peer, use [channels.getSendAs](https://core.telegram.org/method/channels.getSendAs) with `for_live_stories` set and pass one of the returned peers to [phone.sendGroupCallMessage](https://core.telegram.org/method/phone.sendGroupCallMessage).`send_as`.
