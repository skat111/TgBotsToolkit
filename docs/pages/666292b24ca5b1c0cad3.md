## Description

Adds a message to a quick reply shortcut. If shortcut doesn't exist and there are less than [getOption](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1get_option.html)("quick\_reply\_shortcut\_count\_max") shortcuts, then a new shortcut is created. The shortcut must not contain more than [getOption](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1get_option.html)("quick\_reply\_shortcut\_message\_count\_max") messages after adding the new message. Returns the added message.

Returns object\_ptr<QuickReplyMessage>.
