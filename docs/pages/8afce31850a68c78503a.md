## Description

Adds a new media preview to the beginning of the list of media previews of a bot. Returns the added preview after addition is completed server-side. The total number of previews must not exceed [getOption](https://core.telegram.org/tdlib/docs/classtd_1_1td__api_1_1get_option.html)("bot\_media\_preview\_count\_max") for the given language.

Returns object\_ptr<BotMediaPreview>.
