# e2e.chain.groupBroadcastNonceReveal

Source: https://core.telegram.org/constructor/e2e.chain.groupBroadcastNonceReveal

Reveal message for the [E2E conference call emoji verification protocol](https://core.telegram.org/api/end-to-end/group-calls#commit-reveal-protocol-workflow).

When submitting this broadcast to the server, use the canonical constructor ID shown in the schema; broadcasts returned by the server use the constructor ID described in the [subchain documentation](https://core.telegram.org/api/end-to-end/group-calls#subchains).

```
e2e.chain.groupBroadcastNonceReveal#83f4f9d8 signature:int512 user_id:int64 chain_height:int32 chain_hash:int256 nonce:int256 = e2e.chain.GroupBroadcast;
```

### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **signature** | [int512](https://core.telegram.org/type/int512) | Signature of the TL-serialized reveal message with the `signature` field zeroed out. |
| **user\_id** | [int64](https://core.telegram.org/type/int64) | Telegram user ID of the participant sending the reveal. |
| **chain\_height** | [int32](https://core.telegram.org/type/int32) | Height of the main-chain block for which verification emojis are being generated. |
| **chain\_hash** | [int256](https://core.telegram.org/type/int256) | Hash of the main-chain block for which verification emojis are being generated. |
| **nonce** | [int256](https://core.telegram.org/type/int256) | Original random nonce; valid only if its SHA256 hash matches the previously committed `nonce_hash`. |
