### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **flags** | [#](https://core.telegram.org/type/%23) | Flags, see [TL conditional fields](https://core.telegram.org/mtproto/TL-combinators#conditional-fields) |
| **chat\_id** | [long](https://core.telegram.org/type/long) | [Chat](https://core.telegram.org/api/channel) ID |
| **date** | [int](https://core.telegram.org/type/int) | When did this event occur |
| **actor\_id** | [long](https://core.telegram.org/type/long) | User that triggered the change (inviter, admin that kicked the user, or the even the **user\_id** itself) |
| **user\_id** | [long](https://core.telegram.org/type/long) | User that was affected by the change |
| **prev\_participant** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).0?[ChatParticipant](https://core.telegram.org/type/ChatParticipant) | Previous participant info (empty if this participant just joined) |
| **new\_participant** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).1?[ChatParticipant](https://core.telegram.org/type/ChatParticipant) | New participant info (empty if this participant just left) |
| **invite** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).2?[ExportedChatInvite](https://core.telegram.org/type/ExportedChatInvite) | The invite that was used to join the group |
| **qts** | [int](https://core.telegram.org/type/int) | New **qts** value, see [updates »](https://core.telegram.org/api/updates) for more info. |
