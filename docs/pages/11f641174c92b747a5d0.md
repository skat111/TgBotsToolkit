# e2e.chain.block

Source: https://core.telegram.org/constructor/e2e.chain.block

A block in the [main E2E conference call blockchain](https://core.telegram.org/api/end-to-end/group-calls#block-structure), containing state changes for the call and the resulting state proof.

When submitting blocks to the server, use the canonical constructor ID shown in the schema; blocks returned by the server use the incremented constructor ID described in the [subchain documentation](https://core.telegram.org/api/end-to-end/group-calls#subchains).

```
e2e.chain.block#639a3db6 signature:int512 flags:# prev_block_hash:int256 changes:Vector<e2e.chain.Change> height:int state_proof:e2e.chain.StateProof signature_public_key:flags.0?int256 = e2e.chain.Block;
```

### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **signature** | [int512](https://core.telegram.org/type/int512) | Signature of the TL-serialized block with the `signature` field zeroed out. |
| **flags** | [#](https://core.telegram.org/type/%23) | Flags, see [TL conditional fields](https://core.telegram.org/mtproto/TL-combinators#conditional-fields) |
| **prev\_block\_hash** | [int256](https://core.telegram.org/type/int256) | SHA256 hash of the previous accepted main-chain block. |
| **changes** | [Vector](https://core.telegram.org/type/Vector%20t)<[e2e.chain.Change](https://core.telegram.org/type/e2e.chain.Change)> | State changes applied by this block; a valid block must contain at least a group-state change or key-value change. |
| **height** | [int](https://core.telegram.org/type/int) | Sequential block number; it must be exactly one more than the locally accepted height. |
| **state\_proof** | [e2e.chain.StateProof](https://core.telegram.org/type/e2e.chain.StateProof) | Resulting blockchain state after all changes in this block are applied. |
| **signature\_public\_key** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).0?[int256](https://core.telegram.org/type/int256) | Public key of the participant that created and signed the block; may be omitted when it matches the first participant's key, except at height `0`. |
