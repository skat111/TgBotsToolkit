# PrivacyKey

Source: https://core.telegram.org/type/PrivacyKey

Privacy **keys** together with [privacy rules »](https://core.telegram.org/api/privacy#privacy-rules) indicate *what* can or can't someone do and are specified by a [PrivacyKey](https://core.telegram.org/type/PrivacyKey) constructor, and its input counterpart [InputPrivacyKey](https://core.telegram.org/type/InputPrivacyKey).

See the [privacy documentation »](https://core.telegram.org/api/privacy) for more info.

### Constructors

| Constructor | Description |
| --- | --- |
| [privacyKeyStatusTimestamp](https://core.telegram.org/constructor/privacyKeyStatusTimestamp) | Whether we can see the last online timestamp of this user.  Note that if *we* decide to hide our exact last online timestamp to someone (i.e., users A, B, C, or all users) **and** we do not have a [Premium](https://core.telegram.org/api/premium) subscription, we won't be able to see the exact last online timestamp of those users (A, B, C, or all users), even if those users *do* share it with us.  If those users *do* share their exact online status with us, but we can't see it due to the reason mentioned above, the `by_me` flag of [userStatusRecently](https://core.telegram.org/constructor/userStatusRecently), [userStatusLastWeek](https://core.telegram.org/constructor/userStatusLastWeek), [userStatusLastMonth](https://core.telegram.org/constructor/userStatusLastMonth) will be set. |
| [privacyKeyChatInvite](https://core.telegram.org/constructor/privacyKeyChatInvite) | Whether the user can be invited to chats |
| [privacyKeyPhoneCall](https://core.telegram.org/constructor/privacyKeyPhoneCall) | Whether the user accepts phone calls |
| [privacyKeyPhoneP2P](https://core.telegram.org/constructor/privacyKeyPhoneP2P) | Whether P2P connections in phone calls with this user are allowed |
| [privacyKeyForwards](https://core.telegram.org/constructor/privacyKeyForwards) | Whether messages forwarded from the user will be [anonymously forwarded](https://telegram.org/blog/unsend-privacy-emoji#anonymous-forwarding) |
| [privacyKeyProfilePhoto](https://core.telegram.org/constructor/privacyKeyProfilePhoto) | Whether the profile picture of the user is visible |
| [privacyKeyPhoneNumber](https://core.telegram.org/constructor/privacyKeyPhoneNumber) | Whether the user allows us to see his phone number |
| [privacyKeyAddedByPhone](https://core.telegram.org/constructor/privacyKeyAddedByPhone) | Whether this user can be added to our contact list by their phone number |
| [privacyKeyVoiceMessages](https://core.telegram.org/constructor/privacyKeyVoiceMessages) | Whether the user accepts voice messages |
| [privacyKeyAbout](https://core.telegram.org/constructor/privacyKeyAbout) | Whether people can see your bio |
| [privacyKeyBirthday](https://core.telegram.org/constructor/privacyKeyBirthday) | Whether the user can see our birthday. |
| [privacyKeyStarGiftsAutoSave](https://core.telegram.org/constructor/privacyKeyStarGiftsAutoSave) | Whether received [gifts](https://core.telegram.org/api/gifts) will be automatically displayed on our profile |
| [privacyKeyNoPaidMessages](https://core.telegram.org/constructor/privacyKeyNoPaidMessages) | Who can send you messages without paying, if [paid messages »](https://core.telegram.org/api/paid-messages) are enabled. |
| [privacyKeySavedMusic](https://core.telegram.org/constructor/privacyKeySavedMusic) | Whether the user can see the [songs we pinned to our profile »](https://core.telegram.org/api/profile#music). |

### Related pages

#### [Privacy settings](https://core.telegram.org/api/privacy)

Telegram allows users to specify granular privacy settings, choosing which users can or can't interact with them in certain ways.

#### [PrivacyKey](https://core.telegram.org/type/PrivacyKey)

Privacy **keys** together with [privacy rules »](https://core.telegram.org/api/privacy#privacy-rules) indicate *what* can or can't someone do and are specified by a [PrivacyKey](https://core.telegram.org/type/PrivacyKey) constructor, and its input counterpart [InputPrivacyKey](https://core.telegram.org/type/InputPrivacyKey).

See the [privacy documentation »](https://core.telegram.org/api/privacy) for more info.

#### [InputPrivacyKey](https://core.telegram.org/type/InputPrivacyKey)

Privacy **keys** together with [privacy rules »](https://core.telegram.org/api/privacy#privacy-rules) indicate *what* can or can't someone do and are specified by a [PrivacyKey](https://core.telegram.org/type/PrivacyKey) constructor, and its input counterpart [InputPrivacyKey](https://core.telegram.org/type/InputPrivacyKey).

See the [privacy documentation »](https://core.telegram.org/api/privacy) for more info.
