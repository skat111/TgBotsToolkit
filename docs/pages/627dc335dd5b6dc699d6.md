# e2e.chain.stateProof

Source: https://core.telegram.org/constructor/e2e.chain.stateProof

Proof of the [E2E conference call blockchain state](https://core.telegram.org/api/end-to-end/group-calls#block-application-process) after a block has been applied.

```
e2e.chain.stateProof#d6b679e6 flags:# kv_hash:int256 group_state:flags.0?e2e.chain.GroupState shared_key:flags.1?e2e.chain.SharedKey = e2e.chain.StateProof;
```

### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **flags** | [#](https://core.telegram.org/type/%23) | Flags, see [TL conditional fields](https://core.telegram.org/mtproto/TL-combinators#conditional-fields) |
| **kv_hash** | [int256](https://core.telegram.org/type/int256) | Root hash of the key-value trie after applying the block. |
| **group_state** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).0?[e2e.chain.GroupState](https://core.telegram.org/type/e2e.chain.GroupState) | Resulting participant and permission state.  **Must** be omitted if the block contains a `ChangeSetGroupState` action.  **Must** be present if the block doesn't contain a `ChangeSetGroupState` action. |
| **shared_key** | [flags](https://core.telegram.org/mtproto/TL-combinators#conditional-fields).1?[e2e.chain.SharedKey](https://core.telegram.org/type/e2e.chain.SharedKey) | Resulting shared key state.  **Must** be omitted if the block contains a `ChangeSetGroupState` action *and/or* a `ChangeSetSharedKey` action.  **Must** be present if the block doesn't contain a `ChangeSetGroupState` action *and/or* a `ChangeSetSharedKey` action. |
