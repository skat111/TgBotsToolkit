# e2e.chain.changeSetGroupState

Source: https://core.telegram.org/constructor/e2e.chain.changeSetGroupState

Updates the [E2E conference call participant list and permissions](https://core.telegram.org/api/end-to-end/group-calls#change-types-for-group-calls), clearing the current shared key state.

```
e2e.chain.changeSetGroupState#2cf17146 group_state:e2e.chain.GroupState = e2e.chain.Change;
```

### Parameters

| Name | Type | Description |
| --- | --- | --- |
| **group_state** | [e2e.chain.GroupState](https://core.telegram.org/type/e2e.chain.GroupState) | New group state containing the participant list and permission bits. |

### Type

[e2e.chain.Change](https://core.telegram.org/type/e2e.chain.Change)
